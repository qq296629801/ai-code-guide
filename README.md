## 快速开始

### 1. 选择合适的 AI 编程工具

根据你的使用场景选择：
- **日常编码**：Cursor、Trae
- **命令行/自动化**：Claude Code、OpenClaw
- **现有 IDE 增强**：GitHub Copilot

### 2. 学习基础 Prompt 技巧

```text
好的提问方式：
- 明确描述目标和上下文
- 提供必要的代码片段
- 说明期望的输出格式

避免的提问方式：
- 模糊的需求描述
- 缺少上下文信息
- 过于宽泛的问题
```

### 3. 实践与迭代

AI 编程是一个需要不断实践和磨合的过程。建议：
- 从小项目开始尝试
- 记录有效的 Prompt 模式
- 逐步扩大 AI 辅助的范围
