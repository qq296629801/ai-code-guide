# Prompt 提示词技巧

## 基础原则

### 1. 明确目标

❌ 不好：
```
帮我写个函数
```

✅ 好：
```
帮我写一个 Python 函数，接收一个字符串列表，返回去重后的列表，保持原始顺序
```

### 2. 提供上下文

❌ 不好：
```
这段代码有 bug，帮我修
```

✅ 好：
```
这是一个用户登录函数，当用户输入空密码时应该返回错误提示，但现在直接崩溃了。
错误信息是 "TypeError: Cannot read property 'length' of undefined"
请帮我找出问题并修复。
```

### 3. 指定格式

```
请用以下格式回复：
1. 问题描述
2. 解决方案
3. 代码示例
4. 注意事项
```

## 常用模板

### 代码生成

```
请用 [语言] 编写一个 [功能描述]。

要求：
- 输入：[输入参数]
- 输出：[输出格式]
- 约束：[性能/兼容性要求]

示例：
输入：xxx
输出：xxx
```

### 代码审查

```
请审查以下代码，关注：
1. 潜在 bug
2. 性能问题
3. 安全隐患
4. 代码风格

[粘贴代码]
```

### 调试帮助

```
我在运行以下代码时遇到了问题：

代码：
[粘贴代码]

错误信息：
[粘贴错误]

预期行为：
[描述预期行为]

请帮我分析和修复。
```

### 学习解释

```
请解释以下代码的工作原理，用简单的语言，适合 [你的水平] 开发者理解：

[粘贴代码]
```

## 进阶技巧

### Chain of Thought（思维链）

让 AI 一步步思考：
```
请一步步分析这个问题，先列出思路，再给出代码。
```

### Few-shot Learning（少样本学习）

给出几个示例：
```
按照以下格式转换数据：

输入："张三,25岁,北京"
输出：{"name": "张三", "age": 25, "city": "北京"}

输入："李四,30岁,上海"
输出：
```

### 角色扮演

```
你是一个有10年经验的 Python 后端开发者，精通高并发和分布式系统。
请帮我设计一个秒杀系统的架构。
```
