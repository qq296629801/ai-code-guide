# AI 编程最佳实践

## 1. 逐步迭代

不要期望一次性生成完美代码。

**推荐流程：**
1. 先让 AI 生成基础框架
2. 逐步添加功能
3. 持续优化和重构

**示例：**
```
第一步：帮我创建一个 Flask 项目的基本结构
第二步：添加用户登录功能
第三步：添加数据库模型
...
```

## 2. 分解复杂任务

❌ 不好：
```
帮我写一个完整的电商系统
```

✅ 好：
```
我需要做一个电商系统，先帮我设计数据模型，包含用户、商品、订单
```

## 3. 善用代码审查

让 AI 审查 AI 生成的代码：
```
请审查上面的代码，检查：
1. 是否有安全漏洞
2. 是否有性能问题
3. 代码风格是否一致
```

## 4. 保留关键上下文

在长对话中，适时总结关键信息：
```
总结一下我们目前完成的工作：
1. 已实现用户登录
2. 已实现商品列表
3. 下一步要实现购物车
```

## 5. 版本控制

AI 编程容易产生大量代码变更，建议：
- 频繁 commit
- 写清楚 commit message
- 重要改动前先创建分支

## 6. 验证测试

永远不要盲目信任 AI 生成的代码：
- 运行测试用例
- 检查边界条件
- 验证安全性

## 7. 安全意识

避免在 Prompt 中泄露敏感信息：
- 不要粘贴 API Key
- 不要粘贴密码
- 不要粘贴生产环境配置

## 8. 学习而非依赖

AI 是工具，不是替代：
- 理解 AI 生成的代码
- 学习新的编程模式
- 积累自己的经验

## 9. 模型选择

不同任务选择不同模型：
| 任务 | 推荐模型 |
|------|----------|
| 代码生成 | Claude 3.5/4, GPT-4 |
| 代码审查 | Claude 3.5/4 |
| 快速补全 | GPT-3.5, Claude Haiku |
| 复杂推理 | Claude 3.5/4, o1 |

## 10. 记录有效模式

建立自己的 Prompt 库：
- 记录有效的提问方式
- 整理常用模板
- 分享给团队成员
